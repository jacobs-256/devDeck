# 设计规范

DevToolBox 是一个信息密集、键盘友好的桌面工具。界面应当安静、精确：中性表面、单一强调色、清晰的层级，以及全项目一致的控件行为。插件通过同一套 token 继承外观，让整个产品看起来像一个应用。

## 设计原则

1. **内容优先**：边框低调、表面安静；强调色只用于操作、链接与焦点。
2. **密集但可读**：正文 13–14px，8px 间距节奏，控件高度 34px、分段项 28px。
3. **用 token 换肤**：组件不写死颜色；深色与浅色是同一设计的两套 token。
4. **控件一致**：按钮、输入框、标签页、徽章的高度、圆角与焦点样式统一。
5. **插件与宿主同源**：Marketplace iframe 使用 `marketplace/shared/theme/` 中镜像的 token。

## 品牌

- 文字标识：**DevToolBox**，侧边栏 15px、半粗体。
- 图标：32×32 圆角方块，6px 圆角，轻阴影。
- 强调色：蓝色。用于主操作、激活导航、链接与焦点，不用于大面积背景或装饰。

## 字体

| Token         | 字号 | 用途                 |
| ------------- | ---- | -------------------- |
| `--text-xs`   | 11px | 徽章、表头、元信息   |
| `--text-sm`   | 12px | 标签、帮助文本、表格 |
| `--text-base` | 14px | 正文、控件           |
| `--text-md`   | 15px | 卡片标题、侧边栏品牌 |
| `--text-lg`   | 18px | 工具标题、对话框标题 |
| `--text-xl`   | 22px | 区块标题             |
| `--text-2xl`  | 28px | 页面标题             |

- 无衬线字体：系统 UI + Noto Sans SC / PingFang / 微软雅黑。
- 等宽字体：系统 monospace；用于载荷、PEM、IP、diff、日志。
- 字重：正文 400，标签/按钮 500，标题 600，页面标题 680。
- 行高：正文 1.55，标题 1.25。

## 间距与形状

- 间距：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40（`--space-1`…`--space-10`）。
- 圆角：6 / 10 / 14 / 18 / 全圆角。
- 控件高度：34px（`--control-height`）。
- 侧边栏 248px，内容最大宽度 1280px。

## 层级与动效

- `--shadow-sm`：卡片、激活标签页、主按钮。
- `--shadow-md`：插件卡片悬停。
- `--shadow-lg`：对话框。
- 过渡：悬停/焦点 120ms，卡片抬升 180ms。
- 焦点环：3px `--focus-ring` + 强调色边框，禁止移除。
- 遵循 `prefers-reduced-motion`，过渡时长收敛到约 0ms。

## 布局

```
┌──────────────┬─────────────────────────────────────────────┐
│ 侧边栏 248px │ 内容区（最大 1280，内边距 32/36）           │
│ 品牌         │ 页头：标题 + 副标题        操作区           │
│ 导航         │ 标签页 / 过滤器                             │
│ 版本         │ 卡片 / 工具布局                             │
│ 页脚         │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

- **外壳**：CSS Grid，侧边栏固定宽度，内容区独立滚动。
- **页头**：标题 28px，副标题 14px 次要色，最宽 72ch；窄屏操作区换行。
- **Marketplace**：卡片自动填充，最小宽度 320px；过滤器位于网格上方。
- **工具**：两栏——236px 导航 + 面板；二者都是带阴影的卡片。面板头部包含标题、描述与分类徽章。
- **断点**：1080px（侧边栏收窄）、900px（侧边栏变顶栏、工具导航堆叠）、640px（单列卡片、页头堆叠）。

## 组件

### 按钮

| 变体             | 用途                                            |
| ---------------- | ----------------------------------------------- |
| `button.primary` | 每个视图/区块唯一主操作：安装、连接、生成、保存 |
| `button`（默认） | 带边框与表面的次要操作                          |
| `button.ghost`   | 低强调操作、过滤器、复制                        |
| `button.danger`  | 破坏性操作（移除、卸载）                        |
| `button.link`    | 行内文字操作                                    |

- 高度 34px，左右 13px，圆角 10px，13px/500。
- 悬停加强边框并提亮背景；按下位移 1px。
- 禁用：45% 不透明度，不可点击。
- 图标与文字间距 6px；纯图标按钮必须提供 aria-label。

### 表单控件

- 输入框/下拉：34px 高，surface-2 背景，1px 边框，10px 圆角。
- 焦点：强调色边框 + 3px 焦点环，不能只依赖 outline。
- 多行文本：9/11px 内边距，最小 96px，可纵向缩放。
- 标签在控件上方（12px/500 次要色）；必填项在标签中加 `*`。
- `.field-row` 底部对齐控件；窄屏自动换行。
- `.field.compact` 宽 148px，用于端口/数量；`.field.grow` 占满剩余空间。
- 复选框使用强调色，尺寸 15px，标签可点击。

### 分段控件与标签页

- `.segmented` 用于工具内互斥模式（编码/解码）。
- `.tabs` 用于页面级分区（目录/已安装）；激活项是 surface-2 轨道上的抬升胶囊。

### 徽章与标签

- 徽章：21px 胶囊，11px/500；变体 `ok`、`warn`、`bad`。
- 标签：等宽 11px，用于权限、域名、环境变量。
- 状态不能只靠颜色表达，必须保留文字（`valid`、`expired`）。

### 卡片、表格、提示

- 卡片：14px 圆角、20px 内边距、1px 边框、shadow-sm；插件卡片悬停抬升。
- 表格：12px 文本，11px 大写表头，行悬停，无竖线。
- 提示条：左侧强调色竖条；错误提示使用错误色与浅背景。
- 空状态：虚线边框、40px 内边距、居中标题与说明。

### 对话框

- 最大宽 740px，18px 圆角，背景模糊，shadow-lg。
- 头部（标题 + 关闭）、可滚动主体、右对齐页脚（取消 + 主操作）。
- 权限行：标题、等宽 id、`privileged`/`unavailable` 徽章、说明；特权行使用警告浅背景。

### 工具导航

- 顶部搜索，分组标题为 11px 大写。
- 条目高 34px、8px 圆角；激活项使用 accent-soft 背景与强调色文字。
- 面板显示标题、单行描述、分类徽章与分隔线。

## 可访问性

- 正文对比度 ≥ 4.5:1，大文本与 UI 边框 ≥ 3:1。
- 所有交互元素可键盘到达，并有可见的 `:focus-visible` 状态。
- 按钮与输入至少 34px 高；复选框命中区域包含标签。
- 使用语义元素（`button`、`nav`、`main`、`header`、`dl`），激活导航加 `aria-current="page"`。
- 状态始终有文字说明，不仅依赖颜色。
- 尊重减少动效设置。

## 插件主题

插件加载 `marketplace/shared/devtoolbox-embed.css`，其中导入 `theme/variables.css` 与 `theme/toolkit.css`。

- `<html>` 上的 `data-theme="light"` 切换 token；SDK 的 `followHostTheme()` 负责设置。
- 使用 `--bg-*`、`--text-*`、`--accent-*`、`--border-*`、`--radius` 与字体变量，禁止硬编码十六进制颜色。
- Toolkit 类：`.dtb-card`、`.dtb-input`、`.dtb-button`、`.dtb-muted`。
- 插件可定义布局样式，但控件高度、圆角与焦点行为应与 toolkit 一致。
